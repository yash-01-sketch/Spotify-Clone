# 🎵 Spotify Clone

I built this as a frontend project to practice JavaScript and DOM manipulation. 
It's a music player inspired by Spotify's UI.

## What it does

- Play and pause songs
- Switch between tracks using Previous and Next
- Seek through a song using the progress bar
- Adjust volume
- Shows current song name and a playing animation

## Built with

- HTML5
- CSS3
- Vanilla JavaScript
